# 智能好友与群邀请审核

AstrBot 插件，支持好友申请和机器人收到的群邀请的全自动、半自动审核。

插件先采集 QQ/群资料，再按黑白名单规则和 0-10 分评分处理。评分可以调用文字模型和视觉模型识别验证信息、头像、昵称、签名、群资料等内容。模型只负责单项评分和理由，最终分数由插件本地计算。

## 安装

将目录放到 AstrBot 的 `data/plugins/astrbot_plugin_smart_request_review`，安装 `requirements.txt` 后重载插件。

插件只支持 aiocqhttp / OneBot v11。

## 审核模式

- **全自动**：总分达到阈值时调用 `set_friend_add_request` 或 `set_group_add_request(sub_type="invite")`；低于阈值拒绝。
- **半自动**：发送带资料和评分推导的审核消息，等待管理员最终处理。

半自动命令必须引用机器人发出的审核消息：

```text
同意
拒绝 [理由]
拉黑 [理由]
```

不引用消息、引用普通消息、引用已处理消息或引用过期消息时，插件不会执行任何审批动作。该行为参考 `astrbot_plugin_relationship`，避免误处理任意 QQ 号。

## 资料和评分

好友默认评分为验证信息 3 分、申请内容规则 1 分、QQ 等级 2 分、头像 2 分、昵称 1 分、签名 1 分。默认达到 5 分通过，QQ 等级默认 15 级增加 1 分。

群邀请默认评分为群资料 3 分、验证信息 2 分、群人数 2 分、群等级 1 分、群简介/公告/精华 2 分。

机器人尚未入群时，群名、人数、公告、精华和成员列表可能无法获取。报告会显示“未知”和接口原因，未知字段不会被当成有效条件。

## 本地黑名单

OneBot 没有统一的好友或邀请人永久拉黑接口，因此插件维护自己的持久化黑名单。默认同一好友或同一邀请人累计被拒 3 次后加入黑名单，之后的申请会自动拒绝；成功通过后清零拒绝次数。

数据保存于 AstrBot 的插件数据目录：`pending.json`、`history.json`、`blacklist.json` 和 `rejections.json`。

## 模型配置

`provider_id` 配置文字审核模型，`vision_provider_id` 配置视觉模型。留空时按当前会话模型和已加载 provider 兜底。头像以 `base64://` 图片传给 AstrBot 的 `context.llm_generate`，模型不可用时对应评分项记为未知，不会让申请事件崩溃。
